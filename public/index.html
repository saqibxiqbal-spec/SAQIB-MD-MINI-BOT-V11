Help

FAQ

Pairing code kaise use karein?
WhatsApp kholo ➜ Settings ➜ Linked Devices ➜ Link a Device ➜ "Link with phone number instead" chuno ➜ yahan diya 8-digit code type karo. Bas! 🎉
Kitne numbers link kar sakte hain?
Ek hi bot par 500 tak WhatsApp numbers link ho sakte hain. Har number ka apna session hota hy.
Bot offline ho jaye to kya hoga?
MongoDB ya SESSION_ID set hone par restart ke baad bhi saare linked numbers khud reconnect ho jate hain — dobara pairing ki zarurat nahi.
Default command prefix kya hy?
Default prefix . hy (dot). Example: .menu, .ping, .alive.
Ye bot kahan deploy hota hy?
Render, Railway, Koyeb, Fly.io ya kisi bhi Node host par. Dockerfile aur render.yaml included hain.
